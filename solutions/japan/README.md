# Japan solutions

- [`joai_2025_gas.py`](joai_2025_gas.py) builds a submission and runs stratified weighted-F1 cross-validation for the JOAI 2025 multimodal gas-classification task. See the [report](../../reports/japan/joai_2025_gas_classification.md) for task details, source links, licensing, and score limitations.

The competition data and images are not included. The task materials specify CC BY-NC-SA 3.0 IGO; the report provides attribution and links instead of reproducing those materials.
